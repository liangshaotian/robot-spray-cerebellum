# 汽车喷涂验收范围

当前软件0.3.1、HTTP/JSON v1；平台RoboDK5.9.0.25042，项目华沿E12（官方旧品牌Han's E12，原尺寸）。

- 完整Artec E350网格显示与碰撞；前车门局部人工选区及遮罩。
- 新权重159个运动点和135层覆盖实际完成播放，按5mm/1°完整采样检查通过。原始记录见`../experiments/automotive_20261029/e12_execution.json`。
- `evaluate_automotive.py --verify-recorded`复现同一车门3工况×3方法的9次检查；不是独立车型泛化测试。
- 汽车资产安装校验SHA256、拒绝覆盖被修改的本地资产，保留v1接口和既有策略标识。
- 原39.1秒视频恢复，保留整车和机械臂视野；只展示原流程，不冒充新权重录屏。

接口测试覆盖提交、幂等、状态持久化、取消、单位/字段/变换校验、点云读取和未知区遮罩。旧汽车接口验收仅用于兼容追溯，不作为当前模型效果证据。

当前策略未优于固定高速参考；几何覆盖不等于真实膜厚或喷涂合格率。模型卡明确现有权重为通用曲面预训练，不能将训练统计当作汽车专用数据规模。尚未验证独立车型、整车全覆盖、自动分割、真实喷枪物理、实体机器人驱动或其他型号。
