# E350汽车喷涂数值对照

共同条件：E350前车门约0.58m²、喷距200mm、名义速度400mm/s、喷幅240mm、搭接率约58.3%、一遍。三种方法×三个给定沉积倍率，共9次同一车门的数值运行，不是独立车型或实物喷涂对照。

| CSV的method | 方法与作用 |
|---|---|
| raster | 固定蛇形路线，400mm/s，不使用RL；作为固定控制参照 |
| fixed_speed | 同一路线，横向偏移0，平滑后趋近500mm/s，不使用RL；用于检查单纯提速的作用 |
| sac | 同一路线基础上，SAC调整横向±10mm及速度300～500mm/s |

`flow_gain`为每次模拟沉积增量的整体倍率，取0.65、1.0、1.2，没有实测气压或流量标定。SAC可读取该倍率；三次使用同一检查点，不重新训练。所有方法使用相同几何沉积模型、动作平滑及边界约束。

`summary.json`中的`gain1_results`是倍率1.0的结果，对应汇报表和热力图；`means_over_conditions`是三个倍率的均值。`rollouts.csv`和`rollouts.json`逐项保留9次数值记录。

指标均按有效曲面面积加权：目标RMSE使用代码设定的相对目标2.2；CV为标准差／均值；覆盖率使用相对沉积量大于0.2的判据；目标±20%面积对应1.76～2.64。它们都不是实测膜厚或工艺合格标准。估计喷涂时间不包含关枪转移、预检和加减速。

`e12_execution.json`是SAC流程的159点RoboDK检查与播放记录，不代表另外两种方法也完成了机械臂执行。设置、目的、定义和结果详见[组会报告](../../docs/EXPERIMENT_20261029.md)。
