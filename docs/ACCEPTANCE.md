# 验收记录

当前版本0.3.0，HTTP/JSON v1；实测平台为RoboDK5.9.0.25042及项目华沿E12（官方旧品牌Han's E12）。

## 多曲面实验

- 45组训练配置、31种训练几何，6组独立验证配置。真实扫描按来源类别在增强前隔离。
- 本机已有base环境、RTX3070Ti Laptop，240,000步、235,000次更新、2,016回合、67.0分钟；部署验证集选择的180,000步模型。
- 10种未见几何×3个模拟增益×3个当前策略，共90次对照；`tools/evaluate_multisurface.py --verify-recorded`已在CPU重算并核对所有公布的平均指标。
- 当前19项单元测试通过，涵盖协议、几何、旧资产兼容、新资产校验、禁止覆盖被修改资产和数据划分。
- E350车门159点与未见合成鞍形138点完成实际RoboDK播放，完整采样运动和碰撞检查通过。
- 贝壳形真实扫描第57点IK分支不连续；海星形真实扫描第78点MoveL检查返回-1，均预检拦截、未执行。其他工件不可据数值评估声称通过机械臂执行。

完整数值与图表见[实验报告](EXPERIMENT_20261029.md)，E12成功和失败见[运动检查](../experiments/multisurface_20261029/results/robot_verification.json)。新注册/移植的干净副本检查见`evidence/multisurface_publication_verification.json`。

## 接口范围

已验证任务提交、幂等重试、状态持久化、取消、输入字段与单位校验、PCD读取、m到mm转换、未知区不跨越、token认证，以及明确标注的mock联调。

当前新模型通过显式观测版本进入同一规划器，保持外部v1字段兼容；几何层新策略推理与完整测试均可离线复现。旧资产和样例的既有接口记录保留用于兼容性追溯，不作为当前模型的效果证据。

未完成实体机械臂通信、真实膜厚与气压标定、任意点云分割、多机械臂或整车覆盖。当前SAC未明显优于简单固定动作，不宣称已建立强泛化或生产喷涂精度。
