# 汽车喷涂验收范围

软件0.3.1、HTTP/JSON v1；平台RoboDK5.9.0.25042，机器人为华沿E12，采用官方Han's E12模型。

- 完整Artec E350网格显示与碰撞；前车门局部人工选区及遮罩。
- E12完成159个运动点的仿真及135层覆盖显示，按5mm/1°采样检查通过。执行记录见`../experiments/automotive_20261029/e12_execution.json`。
- `evaluate_automotive.py --verify-recorded`复现同一车门3工况×3方法的9次检查；不是独立车型泛化测试。
- 汽车资产安装校验SHA256、拒绝覆盖被修改的本地资产，使用v1接口及约定的策略标识。
- 39.1秒视频展示车身、机械臂、TCP轨迹及前车门喷涂过程。

接口测试覆盖提交、幂等、状态持久化、取消、单位/字段/变换校验、点云读取和未知区遮罩。

当前策略未优于固定高速参考；几何覆盖不等于真实膜厚或喷涂合格率。模型卡明确现有权重为通用曲面预训练，不能将训练统计当作汽车专用数据规模。尚未验证独立车型、整车全覆盖、自动分割、真实喷枪物理、实体机器人驱动或其他型号。
